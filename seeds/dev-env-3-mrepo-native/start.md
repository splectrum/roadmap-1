# Start

The initial request, given to the first session in `dev-env-3-mrepo-native`
(a Claude Code cloud session):

> Load the seed from `splectrum/roadmap-1`, folder
> `seeds/dev-env-3-mrepo-native/`, and start with its request
> (`pending/request.md`). You may push to every branch of this repository
> (its layers), and attach `splectrum/splectrum-dev-env-3-mycelium` to read
> from it.

Planting the seed (the request's first step) puts `README.md`,
`CLAUDE.md`, `rules.md` and `docs/` on `main`, and the request with them;
this file is not planted.
