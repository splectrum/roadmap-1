# Start

The initial request, given to the first session in
`dev-env-2-p2p-cluster`:

> Load the seed from `splectrum/roadmap-1`, folder
> `seeds/dev-env-2-p2p-cluster/`, and start with its request
> (`pending/request.md`). You may push to `main`, `pending/default` and
> `execute/main` in this repository, and to the product repositories the
> request names.

Planting the seed (the request's first step) puts `README.md`,
`CLAUDE.md`, `rules.md` and `vision.md` on `main` and the request on
`pending/default`; this file is not planted.
