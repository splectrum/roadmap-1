# Start

The initial request, given to the first session in `dev-env-1-mycelium`:

> Load the seed from `splectrum/roadmap-1`, folder
> `seeds/dev-env-1-mycelium/`, and start with its request
> (`pending/request.md`). You may push to `main`, `pending/default` and
> `execute/main` in this repository.

Planting the seed (the request's first step) puts `README.md`, `CLAUDE.md`
and `rules.md` on `main` and the request on `pending/default`; this file
is not planted.
