# Request: scoping

Scope the roadmap with four products (`roadmap.md`, scoping stage):

1. **Seed template:** the initial repository for a self-contained seed and
   the execution of its request — `prince2/templates/seed/`.
2. **Capability list and sequence:** the capabilities to explore, each with
   the question it answers, and the order they are taken in —
   `capabilities.md`.
3. **Capability categories:** capabilities categorised by URI.
4. **Storing functionality:** how functionality is kept in the repository
   — layers, in `prince2/templates/seed/rules.md`.

`request-spl8.md` is the original request from the seed, kept here until
the scoping answers it.
