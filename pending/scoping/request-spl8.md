# Request

From: spl8, the design phase, 2026-10-26

Plan SPLectrum engineering from this seed, PRINCE2-style and as light as
KISS allows, and decide how we move forward.

The goal is a set of capabilities on which applications can be built, with
home automation as the first application (`roadmap.md`). The principles in
`principles.md` govern how the work is done.

To start:

1. A short project brief: the goal, the scope, and the roles — the human as
   the board directing by exception, the AI as manager and team working
   autonomously within tolerances.
2. Product descriptions for the six capabilities, with quality criteria that
   can be decided from execution data.
3. A detailed plan for the first stage only — research of the capabilities,
   including the connectivity, private data and post-quantum probes — with
   its tolerances and the repositories it needs. Repositories are created by
   the human for now.
4. Work through `open-questions.md` where an answer is needed to proceed.

Once the brief and the first stage plan are settled, this request is done:
remove this file in the commit that records it.
